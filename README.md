I have created a simple racing game in c program called DG Racer.
It uses include graphics.h to render the game.
The consists of a red car(player) and the blue and green cars(traffic).
Points are given according to the cars you dodge.
If the your cars touched the hotbox of the traffic car the game is over.
You can use wasd or arrows keys to manuvre your car.
With this I have taken my first steps to become a game developer.
